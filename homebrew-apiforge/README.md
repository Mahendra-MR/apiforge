# homebrew-apiforge (superseded — see the real tap)

This folder was the original scaffold for the Homebrew tap. The tap is now live as its own repo:

**https://github.com/Mahendra-MR/homebrew-apiforge**

Install with:

```bash
brew tap Mahendra-MR/apiforge
brew install --cask apiforge
```

This folder is kept here for history; edit the cask in the [homebrew-apiforge](https://github.com/Mahendra-MR/homebrew-apiforge) repo directly for future releases, not here.
